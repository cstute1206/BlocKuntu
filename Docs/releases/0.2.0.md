## BlocKuntu 0.2.0 Alpha

This release brings Fedora and Arch-based package support, improvements to everyday focus controls, and fixes for policy persistence and browser-policy cleanup.

### What's new

- **More Linux package options:** one shared Debian/Ubuntu DEB, a Fedora RPM, and an Arch/CachyOS package for x86-64 systems.
- **Protected editing across tiers:** use the Tier 1 edit key for five minutes of broader website and application list editing, including scheduled lists. Active Detox remains protected.
- **Application unlocks by list name:** select eligible Tier 3 application lists by display name or ID. Matching names can unlock multiple active lists together under the existing hourly quota and two-minute expiry.
- **Login startup and tray controls:** start BlocKuntu in the tray at login, reopen its window from the tray, and open Detox or Settings directly. The window opens if the tray is unavailable.
- **List editing improvements:** native deletion confirmations identify the affected item, detected application identities are deduplicated, and list/allowance saves are atomic.
- **Reliability fixes:** improved persistence across daemon processes, safer handling of deleted list identities and unlocks, notification handling, and preservation of unrelated Firefox settings during browser-policy repair and authorized uninstall.

### Install

This alpha targets **fresh installations**. In-place upgrades and preservation of policy/history across an upgrade remain unvalidated and deferred.

Download your package and `SHA256SUMS` from this release. Verify the package against its checksum entry, then install it with the appropriate command:

```bash
# Debian / Ubuntu
sudo apt install ./blockuntu_0.2.0-1_amd64.deb

# Fedora
sudo dnf install ./blockuntu-0.2.0-1.fc43.x86_64.rpm

# Arch / CachyOS
sudo pacman -U ./blockuntu-0.2.0-1-x86_64.pkg.tar.zst
```

Add your desktop user to the group:

```bash
sudo usermod -aG blockuntu "$USER"
```

Sign out and back in, or restart. Open BlocKuntu and store both recovery credentials from the welcome modal before installing the browser extension:

- [Firefox extension](https://addons.mozilla.org/en-US/firefox/addon/blockuntu/)
- [Chrome extension](https://chromewebstore.google.com/detail/blockuntu/opfljaancedgklbpnbpjfhdbbhbfpnoc)
- [Supported browsers and setup](https://github.com/cstute1206/BlocKuntu/blob/Alpha_0.2.0/Docs/supportedBrowsers.md)

### Validation and limits

Native-package acceptance was exercised on Ubuntu 26.04.1 LTS, Fedora 44 Workstation, and CachyOS, including browser blocking, protected edits, uninstall, and selected recovery scenarios. The packages were built on Debian 13, Fedora 43, and rolling Arch respectively. Other versions and derivatives are not individually validated by those results.

Use **Settings → Protected changes and uninstall** for removal when protected actions are available. Active Detox cannot be cancelled and prevents uninstall. BlocKuntu resists casual bypasses; it cannot prevent changes by a user with unrestricted root or sudo access.
